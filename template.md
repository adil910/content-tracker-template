# Template

## Fields

| Field | Type | Notes |
|---|---|---|
| Car / Project | Title | e.g. "Grey G63" |
| Status | Select | See status flow below |
| Progress | Formula / number | 0–100%, shown as a progress bar |
| Shoot date | Date | |
| Videographer | Person | |
| Editor | Person | |
| Raw footage | URL | Drive folder link |
| Final export | URL | Drive folder link |
| Platforms | Multi-select | Instagram, TikTok, YouTube, Website, Listing |
| Post date | Date | |
| Notes | Text | Edit requests and feedback |

## Status flow

`To shoot` → `Shot` → `Uploaded` → `Editing` → `In review` → `Ready` → `Posted`

Suggested progress values: 0, 20, 35, 55, 75, 90, 100.

## Views

- **Gallery**: one card per car with cover image, status colour and progress bar
- **Board**: columns by status
- **Calendar**: by post date
- **My work**: filtered by Editor = me

## Team rules

1. Upload footage to the Drive folder, then paste the link in the card. No links in chat.
2. Update status yourself when you finish your step.
3. Edit requests go in Notes, not in messages.
4. Every card must have a Drive folder before moving to "Uploaded".
