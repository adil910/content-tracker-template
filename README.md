# Content Tracker Template

A simple system for tracking video and photo content from shoot to publish, built for a small team where a videographer shoots and an editor (me) edits and posts.

By **Adil Imtiaz** · [@by_adilvisuals](https://instagram.com/by_adilvisuals)

## The problem

Footage links, status updates and edit requests were scattered across WhatsApp chats. Things got lost and nobody knew what was ready to post.

## The solution

One tracker (built in Notion, later also on the company website) where every car or shoot has one card with its status, links and owner.

## Files

| File | Contents |
|---|---|
| `template.md` | Database fields, status flow, views and team rules |
| `tracker.csv` | Starter table you can import into Notion, Airtable or Google Sheets |
